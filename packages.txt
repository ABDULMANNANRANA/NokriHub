## 3. State management
npm install zustand


## 4. Environment variables
npm install react-native-dotenv

Then add this to `babel.config.js`:

module.exports = {
  presets: ['module:@react-native/babel-preset'],
  plugins: [
    ['module:react-native-dotenv', {
      moduleName: '@env',
      path: '.env',
    }],
  ],
};
